# Aghbahan — Тестер меток (v2, React + shadcn)

Прототип для **авторизованного управления доступом** службы вывоза мусора **Aghbahan**
(Ереван). Веб-приложение по **Bluetooth** управляет устройством **Chameleon Ultra** и
эмулирует ключ-метку подъезда (EM-Marine 125 кГц и MIFARE 13.56 МГц), чтобы сотрудник
открыл дверь дома, который компания обслуживает.

> Инструмент коммунальной службы для входа в **обслуживаемые** дома. На его логике
> строится полноценное приложение сборщика.

## ⚖️ Правовой контекст

Законное, санкционированное управление доступом (не обход систем):
- С каждым клиентом заключён **договор**, по которому клиент — от имени администрации
  дома — **даёт компании право доступа** в свой подъезд (копию ключа-метки).
- Копируется **только** ключ **обслуживаемого** адреса, **с согласия** клиента.
- Дублирование таких ключей в регионе — рутинная легальная процедура.

## Что делает

- Подключение к Chameleon **один раз**; дальше при пробуждении гаджета (кнопкой)
  приложение **само переподключается** — кнопки «Открыть» становятся активными.
- Карточки адресов: *название* + *тип/бренд* (Стандартная EM-Marine, BOON, FNET,
  Hikvision, urban, Другая MIFARE) + *UID*. Хранятся локально (localStorage).
- Тап по адресу → приложение пишет UID в слот Chameleon (EM410x или MIFARE по UID),
  активирует, держит связь ~15 с (окно «поднеси к двери»), затем **авто-отключается**
  → гаджет засыпает (экономия заряда).
- Индикаторы **связи** и **заряда батареи**.

## Стек

Vite + React + TypeScript + Tailwind v4 + shadcn/ui + `chameleon-ultra.js` (Web Bluetooth).
Работает в **Chrome на Android**. Кастомный BLE-адаптер (`src/lib/bleAdapter.ts`)
переподключается без окна выбора.

## Локальный запуск

```bash
npm install
npm run dev
```

Web Bluetooth работает по HTTPS или на `localhost` (нужен Chrome).

## Публикация (GitHub Pages)

Деплой автоматический через GitHub Actions (`.github/workflows/deploy.yml`):
1. Залить этот код в репозиторий `aghbahan-rfid-tester` (ветка `main`).
2. Settings → Pages → **Source: GitHub Actions**.
3. Action соберёт и опубликует → `https://<логин>.github.io/aghbahan-rfid-tester/`.

> `base` в `vite.config.ts` = `/aghbahan-rfid-tester/`. Если имя репозитория другое —
> поменяй `base` на `/<имя-репо>/`.

## Переиспользование

Логика ядра и команды — в [`docs/LOGIC.md`](docs/LOGIC.md) (энергосбережение, типы меток,
BLE-команды) для полноценного приложения сборщика. Ключевые файлы:
`src/lib/bleAdapter.ts` (BLE + переподключение), `src/lib/chameleon.ts` (сервис: сон/эмуляция),
`src/lib/cards.ts` (данные).
